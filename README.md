# 📊 Аналитика занятости и заработной платы в США (BLS QCEW 2023–2025)

Сквозной (End-to-End) проект по инженерии данных и бизнес-аналитике (Data Engineering & Business Intelligence). Проект посвящен анализу динамики рынка труда США, распределения заработных плат и отраслевых трендов на основе официальных данных **Бюро статистики труда США (BLS QCEW)**.

---

## 🎯 Бизнес-контекст, проблемы и результаты

### 1. Проблема (Business Problem)
Анализ региональных и национальных данных о рынке труда сопровождается серьезными техническими и аналитическими сложностями:
* **Риск двойного счета (Double-Counting):** Сырой датасет BLS QCEW одновременно содержит итоговые агрегированные строки (национальный уровень, уровень штатов) и детализированные данные по округам и иерархиям отраслей NAICS. Обычное суммирование строк приводит к завышению финансовых показателей.
* **Сложность моделирования:** Работа с миллионами транзакционных записей требует оптимизированной схемы хранилища (Star Schema) для обеспечения высокой скорости выполнения запросов и чистой отчетности.
* **Принятие управленческих решений:** Руководству необходим понятный интерактивный дашборд для отслеживания изменений зарплат, роста предприятий и ключевых отраслей без технических барьеров.

### 2. Что было сделано (Data Pipeline & Architecture)
* **SQL ETL и очистка данных:** Разработаны представления в SQL Server (`vw_Fact_BLS_County_Level`), отсекающие агрегаты верхнего уровня и изолирующие точные факты по округам и отраслям.
* **Схема «Звезда» (Kimball Star Schema):** Спроектирована многомерная модель Хранилища Данных (`Fact_Employment_Wages`, `Dim_Geography`, `Dim_Industry`, `Dim_Date`) с целочисленными суррогатными ключами.
* **Power BI и явный DAX:** Настроены связи «один ко многим» и написаны явные DAX-меры (`Total Wages`, `Avg Weekly Wage`, `Total Employment`, `Count Distinct Industries`), собранные в отдельную папку `_Measures`.
* **Корпоративный UI/UX дашборд:** Верстован 2-страничный отчет (1280x720 px) со строгим соблюдением модульной сетки, выравнивания и цветовой иерархии.

### 3. Результаты и ценность для бизнеса (Impact)
* **100% точность данных:** Полностью исключено дублирование агрегатов еще на уровне SQL-преобразований.
* **Высокая производительность:** Оптимизированная модель обеспечивает мгновенную отрисовку визуализаций в Power BI при фильтрации миллионов строк.
* **Готовые бизнес-инсайты:** Выявлены высокооплачиваемые отрасли-аутлайеры и концентрации рабочих мест по округам для стратегического планирования ресурсов.

![Схема данных Star Schema](screenshots/03_star_schema_model.png)

### Структура модели:
* **`Fact_Employment_Wages`**: Таблица фактов с ключевыми показателями (`Average_Monthly_Employment`, `Average_Weekly_Wages`, `Total_Wages`).
* **`Dim_Geography`**: Измерение географии (округа и штаты).
* **`Dim_Industry`**: Измерение отраслей (классификация NAICS).
* **`Dim_Date`**: Измерение времени (кварталы и годы).

## 💻 SQL ETL и очистка данных

Чтобы избежать дублирования показателей, SQL-скрипт изолирует точные записи по округам перед загрузкой в Power BI:

```sql
-- Создание очищенного представления фактов (исключение итоговых агрегатов)
CREATE VIEW dbo.vw_Fact_BLS_County_Level AS
SELECT 
    area_fips AS Geography_ID,
    industry_code AS Industry_ID,
    year AS Year,
    qtr AS Quarter,
    annual_avg_estabs AS Active_Establishments,
    annual_avg_emplvl AS Monthly_Employment,
    total_annual_wages AS Total_Wages,
    avg_wkly_wage AS Avg_Weekly_Wage
FROM dbo.qcew_raw
WHERE own_code = '5'                   -- Только частный сектор экономики
  AND qtr IN ('1', '2', '3', '4')      -- Исключение годовых итогов
  AND area_fips NOT LIKE '%000';       -- Исключение итогов по штатам и стране
