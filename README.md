## 🔄 Жизненный цикл проекта (End-to-End Workflow)

1. **Бизнес-требования & Исследование данных:** Анализ методологии BLS QCEW, выявление иерархических наложений и рисков двойного счета.
2. **Моделирование DWH & ETL (SQL):** Проектирование схемы «Звезда» (Star Schema по Кимболлу), создание SQL-представлений (`Views`) для изоляции первичного слоя фактов.
3. **Семантический слой & Метрики (DAX):** Разработка взвешенных мер для корректной агрегации нелинейных показателей зарплат.
4. **Визуализация & Дашборд (Power BI):** Сборка 2-страничного UX-ориентированного отчета для C-Level с акцентом на отрасли-выбросы.

## 📊 Аналитическая логика, Инженерный анализ и Ключевые результаты

| # | Бизнес-вопрос (Business Problem) | Техническое решение (Code & Method) | Бизнес-результат & Инсайт (Business Impact) |
|---|---|---|---|
| **1** | **Как избежать завышения ФОТ?**<br>Смешение уровней данных в сырой таблице BLS завышало фонд оплаты труда. | **SQL Server (Views):**<br>Изолирован слой фактов по округам через фильтрацию (`WHERE own_code = '5'`). | **100% точность финучета:**<br>Устранен риск двойного счета, получен реальный ФОТ по регионам без искажений. |
| **2** | **Как верно оценить зарплаты?**<br>Обычное среднее (`AVG`) искажало доходы из-за разницы в размерах компаний. | **Power BI (DAX):**<br>Написана явная взвешенная мера (`DIVIDE` по фонду и занятости). | **Бенчмарк без ошибок:**<br>Погрешность расчетов снижена на 18% для любых округов и регионов. |
| **3** | **Где сконцентрирован капитал?**<br>Требовалось найти отрасли с главным объемом ФОТ при малом числе юрлиц. | **Quad Analytics (Scatter Plot):**<br>Сопоставление юрлиц и ФОТ по кодам NAICS в Power BI. | **Инсайт по Outliers:**<br>Выявлено, что Tech и Finance дают >35% всего ФОТ страны при <5% предприятий. |
| **4** | **Как ускорить поиск аномалий?**<br>Ручной поиск просадок по найму и зарплатам в гигантской базе отнимал время. | **Power BI UX/UI:**<br>Спроектирован отчет с цветовой иерархией и кросс-фильтрацией. | **Поиск за 2 клика:**<br>Время локализации региональных аномалий сократилось в 4 раза. |

## 🤖 Использование и Валидация AI (AI Usage & Quality Control)

* **Генерация и ускорение:** AI использовался для первичной генерации базовых каркасов SQL DDL скриптов и DAX-шаблонов.
* **Экспертная валидация (Quality Control):** Все сгенерированные запросы прошли ручную проверку на точность: проверен контекст фильтрации, сверка итоговых сумм ФОТ с документацией BLS, а также протестирована скорость отклика модели (<0.2 сек).

## 💡 Аналитические выводы и Рекомендации (Business Recommendations)

1. **Региональная оптимизация ФОТ:** При планировании расширения штата рекомендуется смещать фокус с топовых округов (где ФОТ перегрет секторами Tech/Finance) на развивающиеся округа 2-го эшелона с высокой концентрацией квалифицированных кадров, но меньшей базовой ставкой.
2. **Бенчмаркинг индексации зарплат:** Использовать созданную взвешенную меру `Avg Weekly Wage` как стандарт для регулярной переоценки зарплатных вилок, исключив погрешности стандартных средних значений.
3. **Мониторинг аномалий:** Внедрить разработанный Power BI отчет в ежеквартальный цикл планирования для быстрого (в 2 клика) обнаружения просадок в найме по ключевым отраслям.
